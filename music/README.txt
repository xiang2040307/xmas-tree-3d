把你想听的音频文件放进这个文件夹，刷新网页就会自动从第一首开始播放。

支持的格式：mp3 / m4a / aac / wav / ogg / flac / webm
播放顺序：按文件名排序（想调整顺序就给文件加数字前缀，例如 01-xxx.mp3、02-xxx.mp3）

说明：
- 这里放的是「初始音乐/默认歌单」，每次打开页面都会自动载入。
- 如果这里没有音频文件，页面会用内置的三首颂歌（平安夜 / 铃儿响叮当 / 圣诞快乐）。
- 网页里的「🎵 我的音乐」按钮可以临时载入别的歌，刷新后会恢复到本文件夹的歌单。
- 浏览器规定自动播放要用户交互授权：如果打开后没声音，点一下页面任意位置或 ♪ 音乐按钮即可。
