# ✦ 圣诞之夜 · 3D 粒子圣诞树

一棵华丽的、可以互动的圣诞树：粒子从爆炸中缓缓聚成树形，彩灯追逐、雪花纷飞、极光流转，还有手势控制、许愿、照片挂饰和背景音乐。

> **这是一个"开箱即用"的网页作品。** 你不需要懂编程——照着下面的步骤做，双击一个文件就能看到。

---

## 🚀 第一次使用（电脑小白看这里）

### 第 1 步：安装 Node.js（只需要做一次）

1. 打开网址 **https://nodejs.org/**
2. 下载页面上带 **LTS** 字样的那个版本（比如 20.x、22.x）
3. 双击下载的文件，一路点"下一步"直到装完

> 已经装过 Node.js 的可以跳过这一步。不确定装没装？双击 `start.cmd`，如果提示"没有检测到 Node.js"，就是没装。

### 第 2 步：双击 `start.cmd`

打开项目文件夹（就是你现在看到这个说明的文件夹），**双击 `start.cmd`**。

- 会先弹出一个黑色命令行窗口，显示"正在点亮圣诞树…"
- 接着你的**默认浏览器**（一般是 Edge）会自动打开，圣诞树就出现了 🎄
- 如果浏览器没有自动打开，手动在浏览器地址栏输入：**http://127.0.0.1:8080/**

> 那个黑窗口是本地服务器，**用的时候别关它**。看完想关闭时，直接关掉黑窗口即可。

就这么简单！无需联网、无需构建、无需安装其他东西。

## 🎵 换成自己喜欢的音乐

**背景音乐默认是开着的**，打开页面就会自动播放。想换歌有两种方式：

### 方式一：放进 `music/` 文件夹（推荐，永久生效）

1. 打开项目里的 **`music/`** 文件夹
2. 把你的音乐文件（mp3、m4a、wav、ogg、flac 等）拷进去
3. 刷新网页，就会自动播放这里的歌，以后每次打开都用它
4. 想按顺序播放？给文件名前面加数字，比如 `01-圣诞歌.mp3`、`02-xxx.mp3`
5. 想换回内置的圣诞颂歌？把音频文件移出 `music/` 文件夹，刷新即可

### 方式二：临时换歌（刷新后不保留）

点工具坞的 **♪ 音乐** 按钮暂停/播放，点 **⏭ 切歌** 按钮（或按键盘 `N`）切换下一首。

> **小提示**：浏览器规定自动播放需要用户允许。如果打开页面后没声音，随便点一下页面任意位置，音乐就会开始播放。这是浏览器的规矩，所有网站都一样，不是坏了。

## 🖼️ 换成自己的照片

1. 打开项目里的 **`photos/`** 文件夹
2. 把你的照片（jpg、png 等）拷进去
3. 刷新网页，照片会自动做成拍立得挂饰挂到树上（最多 7 张，按文件名排序）
4. 点击树上的照片可以看大图

> 也可以点工具坞的 **🖼 照片** 按钮临时上传，但刷新后不保留；想固定下来请用 `photos/` 文件夹方式。

## ❓ 常见问题

**Q：双击 `start.cmd` 没反应 / 一闪而过？**
A：① 确认已安装 Node.js；② 右键 `start.cmd` → 打开方式 → 选"命令提示符"；③ 或者在文件夹地址栏输入 `cmd` 回车，然后手动输入 `node launcher.mjs`。

**Q：浏览器没自动打开？**
A：手动打开浏览器，在地址栏输入 `http://127.0.0.1:8080/`。

**Q：打开发现是英文/乱码的提示？**
A：`start.cmd` 已设置为中文编码，正常显示中文。若个别系统仍乱码，不影响使用。

**Q：不要直接双击 `index.html` 吗？**
A：不要。必须通过 `start.cmd` 启动的本地服务器访问，直接双击 `index.html` 手势和部分功能会失效。

**Q：想换端口？**
A：把 `start.cmd` 拖到命令行窗口，后面加空格和端口号，如 `start.cmd 8123`，然后用 `http://127.0.0.1:8123/` 访问。

## 🔧 给开发者（可选阅读）

无需构建、无外部 CDN 依赖——three.js 与 MediaPipe 都已放在 `vendor/`，断网也能跑。

- **树体**：约 6.2 万个自定义 GLSL 粒子构成 17 条螺旋枝股，叠加 3 条金色灯带、900 颗追逐彩灯、88 个菲涅尔材质挂饰。开场粒子从爆炸态聚拢成形（`uForm` uniform 驱动顶点着色器插值，约 4.6 秒）。
- **辉光**：`EffectComposer` + `UnrealBloomPass` + `OutputPass`，ACESFilmic 色调映射；所有片元输出经 `hdrSafe()` 限幅，避免 HDR 半浮点缓冲溢出造成的黑块。
- **环境**：程序化生成的星云天穹、星空、极光、雪山剪影、冰面反光与循环飘雪，全部由着色器绘制，无贴图资源。
- **烟花**：`fireworks.js` 用 CPU 维护上升火箭与爆炸光粒的对象池，GLSL 加色渲染；背景层持续有多发升空绽放（金/红/绿圣诞配色为主），可用工具坞 ✨ 或 `B` 键开关。片元经 `hdrSafe()` 限幅，避免辉光管线的 HDR 溢出。
- **音乐**：`AudioEngine` 用 Web Audio API 实时合成三首公有领域圣诞颂歌；`music/` 里的本地音频经 `/api/music` 扫描后用 `HTMLAudioElement` + `MediaElementAudioSourceNode` 接入，页面启动自动载入并播放，受自动播放策略限制时首次交互解锁。
- **照片**：`photos/` 里的图片经 `/api/photos` 扫描后自动载入为拍立得挂饰。
- **手势**：`@mediapipe/tasks-vision`，GPU 优先、失败自动回退 CPU；掌心平滑 + 捏合迟滞。双手开合缩放。
- **性能**：空闲自动巡航、可见性裁剪、DPR ≤ 2；桌面 1600×900 下实测约 165fps。

├── index.html          页面结构与 UI
├── server.js           零依赖静态服务器
├── start.cmd           Windows 一键启动（双击这个）
├── launcher.mjs        启动助手：起服务器 + 打开默认浏览器
├── css/style.css       界面样式
├── js/
│   ├── main.js         主程序：渲染循环、交互、UI 绑定
│   ├── shaders.js      全部自定义 GLSL 着色器
│   ├── tree.js         圣诞树构建（粒子/灯带/挂饰/星）
│   ├── scenes.js       天空/星空/地面/雪/极光
│   ├── photos.js       程序化拍立得照片系统
│   ├── wishes.js       许愿光字系统
│   ├── gesture.js      MediaPipe 手势引擎

├── music/              【放音频 = 初始音乐，自动播放】
├── photos/             【放照片 = 自动挂到树上】
├── shots/              截图输出目录
├── tools/              开发调试脚本（使用者可忽略）
